# まるっと三角関数

度数法・弧度法を切り替えて、−5π〜5π（−900°〜900°）の有名角の sin / cos / tan を学ぶサイトです。30°と45°の整数倍を出題し、tan が未定義となる角度を除外します。分数やルートの選択肢で回答し、答え合わせ後に単位円と座標を確認できます。

## 実行

Node.js 18 以上を使用します。外部パッケージのインストールは不要です。

```sh
npm start
```

ポートは既定で 3000 です。`PORT` 環境変数で変更できます。

```sh
npm test
```

全出題角の値、弧度法の約分、ランダム出題を検証します。

数式は MathJax 3.2.2（jsDelivr）で表示します。CDN が利用できない場合も、文字の分数・ルート表示でクイズを使用できます。OS の動きを減らす設定ではアニメーションを抑制します。

## オンライン対戦

`battle.html` は1対1の対戦ページです。名前を入力してロビーへ入り、待機中の相手に対戦申請を送れます。相手が承諾すると、5秒後に同じ10問で速さ勝負が始まります。ログイン画面はなく、Firebase の匿名認証を使います。

Firebase の設定・ルール・検証手順は [firebase/SETUP.md](firebase/SETUP.md) に記載しています。Realtime Database の URL、匿名認証の有効化、ルールの公開が必要です。接続設定が完了していなくても、同じブラウザーの2タブで「お試し対戦」を利用できます。お試し対戦は別端末に接続しません。

## ログイン・レーティング

`account.html` で校内用（7桁の生徒番号）または一般用（メールアドレス）アカウントを登録・ログインできます。ログイン済み同士の対戦は初期1500・K=32の Elo レーティングをサーバーで集計します。`rankings.html` では全体・校内用・一般用のランキングを確認できます。ゲストとお試し対戦はレート対象外です。

本番では Email/Password 認証の有効化、Cloud Functions の配置、最新の Database ルールが必要です。詳しくは [firebase/ACCOUNTS.md](firebase/ACCOUNTS.md) を参照してください。
